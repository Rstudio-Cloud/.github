## Starting an RStudio Session

Begin by identifying whether the intended workflow uses a locally running development environment or a cloud-hosted workspace. Confirm the product and service before creating a project or moving data.

1. **Choose an Environment:** Decide whether a local workspace or a supported cloud service fits the project.
2. **Check Requirements:** Review the selected product's requirements and supported capabilities.
3. **Prepare Project Files:** Gather the scripts, datasets, and supporting documents needed for the task.
4. **Create a Project:** Set up a clearly named workspace for the analytical work.
5. **Run and Review Code:** Execute scripts and inspect outputs, messages, and visualizations.
6. **Save Your Work:** Keep project files organized and maintain separate backups of important data.

**Data safety note:** Keep backup copies of valuable datasets and avoid overwriting source files during analysis. Only use data that you own or are authorized to access.
